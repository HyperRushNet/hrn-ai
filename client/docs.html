AIClient Referentie

Een modulaire, promise-gebaseerde JavaScript wrapper voor het genereren van tekst en afbeeldingen via de Pollinations AI API. Nul afhankelijkheden, direct bruikbaar in de browser.

Installatie

Kopieer onderstaande klasse naar je JavaScript project. De klasse maakt gebruik van de native Fetch API en vereist geen externe bibliotheken.

class AIClient {
  constructor() {
    this.config = {
      apiKey: null,
      model: 'openai',
      systemPrompt: 'You are a helpful assistant.',
      type: 'text',
      width: 1024,
      height: 1024,
      history: []
    };
  }

  // Configuraties
  setApiKey(key) {
    if (key && typeof key === 'string') this.config.apiKey = key;
    return this;
  }

  setModel(modelId) {
    if (modelId && typeof modelId === 'string') this.config.model = modelId;
    return this;
  }

  setSystemPrompt(prompt) {
    if (prompt && typeof prompt === 'string') this.config.systemPrompt = prompt;
    return this;
  }

  setType(type) {
    if (type === 'text' || type === 'image') this.config.type = type;
    else console.warn("Invalid type. Use 'text' or 'image'.");
    return this;
  }

  setWidth(w) { this.config.width = parseInt(w); return this; }
  setHeight(h) { this.config.height = parseInt(h); return this; }

  // Hoofdfunctie
  async generate(input) {
    if (!input) throw new Error("Input prompt is required.");
    return this.config.type === 'image' 
      ? await this._genImg(input) 
      : await this._genTxt(input);
  }

  // Tekst generatie (intern)
  async _genTxt(prompt) {
    this.config.history.push({ role: 'user', content: prompt });
    const body = {
      model: this.config.model,
      messages: [{ role: 'system', content: this.config.systemPrompt }, ...this.config.history]
    };
    const headers = { 'Content-Type': 'application/json' };
    if (this.config.apiKey) headers.Authorization = `Bearer ${this.config.apiKey}`;

    const r = await fetch('https://gen.pollinations.ai/v1/chat/completions', {
      method: 'POST',
      headers,
      body: JSON.stringify(body)
    });
    const d = await r.json();
    if (!r.ok) throw new Error(d.error?.message || `Error: ${r.status}`);
    const t = d.choices[0].message.content;
    this.config.history.push({ role: 'assistant', content: t });
    return t;
  }

  // Afbeelding generatie (intern)
  async _genImg(prompt) {
    const p = new URLSearchParams();
    if (this.config.apiKey) p.append('key', this.config.apiKey);
    p.append('model', this.config.model);
    p.append('width', this.config.width);
    p.append('height', this.config.height);
    p.append('nologo', 'true');
    const r = await fetch(`https://gen.pollinations.ai/image/${encodeURIComponent(prompt)}?${p}`);
    if (!r.ok) throw new Error(`Error: ${r.status}`);
    return URL.createObjectURL(await r.blob());
  }
}

Methoden

.setType(type)

Schakel tussen tekstgeneratie en afbeeldinggeneratie.

Parameter Type Beschrijving
type string Moet "text" of "image" zijn.
  • "text": Geeft een string antwoord terug.
  • "image": Geeft een Blob URL terug voor <img> tags.
.generate(prompt) Async

Triggert de API-aanvraag op basis van de huidige configuratie. Retourneert een Promise die de gegenereerde content bevat.

Parameter Type Beschrijving
prompt string De inputprompt voor het model. Verplicht. 
const response = await ai.generate("Hallo wereld");
.setApiKey(key)

Stel een optionele API-sleutel in voor geauthenticeerde verzoeken.

.setModel(modelId)

Selecteer het te gebruiken AI-model. Zie de parametersectie voor beschikbare opties.

.setSystemPrompt(prompt)

Definieer het systeembericht dat het gedrag van de AI stuurt.

Beschikbare Modellen

Type Model ID Gebruik
Tekst openai Algemene assistent (standaard)
Tekst claude Anthropic Claude model
Tekst mistral Mistral AI model
Afbeelding flux Flux afbeeldingsmodel (standaard)
Afbeelding turbo Snelle generatie
Let op: Modelbeschikbaarheid kan veranderen. Raadpleeg de Pollinations documentatie voor de meest actuele lijst.

Voorbeeld: Tekst Generatie

Een eenvoudige AI-assistent configureren:

const ai = new AIClient();

async function chat() {
  const text = await ai
    .setModel("openai")
    .setSystemPrompt("Je bent een poëtische assistent.")
    .generate("Leg programmeren uit in 2 zinnen.");
  
  console.log(text);
}

// Output: "Code is de taal waarin logica tot leven komt, 
// een symfonie van instructies die machines doet dromen."

Voorbeeld: Afbeelding Generatie

Een hoge resolutie afbeelding genereren:

const ai = new AIClient();

async function maakKunst() {
  const url = await ai
    .setType("image")
    .setModel("flux")
    .setWidth(1280)
    .setHeight(720)
    .generate("Een neon cyberpunk kat in de ruimte");

  // Toon in DOM
  const img = document.createElement('img');
  img.src = url;
  document.body.appendChild(img);
}

Voorbeeld: Gespreksgeschiedenis

De klasse houdt automatisch de gespreksgeschiedenis bij voor context:

const ai = new AIClient();

async function conversatie() {
  // Eerste bericht
  await ai.generate("Mijn naam is Jan.");
  
  // AI onthoudt de naam uit vorige context
  const antwoord = await ai.generate("Hoe heet ik?");
  console.log(antwoord); // "Je heet Jan."
  
  // Reset geschiedenis
  ai.config.history = [];
}
