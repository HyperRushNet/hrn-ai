AIClient Reference

Een modulaire, belofte-gedreven JavaScript class voor tekst en afbeeldingen via de Pollinations API.

Installatie

Kopieer de class naar je project. Geen dependencies.

class AIClient{constructor(){this.config={apiKey:null,model:'openai',systemPrompt:'You are a helpful assistant.',type:'text',width:1024,height:1024,history:[]}}setApiKey(key){if(key&&typeof key==='string')this.config.apiKey=key;return this}setModel(modelId){if(modelId&&typeof modelId==='string')this.config.model=modelId;return this}setSystemPrompt(prompt){if(prompt&&typeof prompt==='string')this.config.systemPrompt=prompt;return this}setType(type){if(type==='text'||type==='image')this.config.type=type;else console.warn("Gebruik 'text' of 'image'.");return this}setWidth(w){this.config.width=parseInt(w);return this}setHeight(h){this.config.height=parseInt(h);return this}async generate(input){if(!input)throw new Error("Input is vereist.");return this.config.type==='image'?await this._genImg(input):await this._genTxt(input)}async _genTxt(prompt){this.config.history.push({role:'user',content:prompt});const body={model:this.config.model,messages:[{role:'system',content:this.config.systemPrompt},...this.config.history]};const headers={'Content-Type':'application/json'};if(this.config.apiKey)headers.Authorization=`Bearer ${this.config.apiKey}`;try{const r=await fetch('https://gen.pollinations.ai/v1/chat/completions',{method:'POST',headers,body:JSON.stringify(body)});const d=await r.json();if(!r.ok)throw new Error(d.error?.message||`Error: ${r.status}`);const t=d.choices[0].message.content;this.config.history.push({role:'assistant',content:t});return t}catch(e){this.config.history.pop();throw e}}async _genImg(prompt){const p=new URLSearchParams();if(this.config.apiKey)p.append('key',this.config.apiKey);p.append('model',this.config.model);p.append('width',this.config.width);p.append('height',this.config.height);p.append('nologo','true');const r=await fetch(`https://gen.pollinations.ai/image/${encodeURIComponent(prompt)}?${p}`);if(!r.ok)throw new Error(`Fout: ${r.status}`);return URL.createObjectURL(await r.blob())}}

Configuratie

Alle setters retourneren this voor chaining.

.setApiKey(key)
API sleutel (optioneel voor sommige modellen).
.setModel(modelId)
Model ID (bv. "openai", "flux").
.setSystemPrompt(prompt)
Persona (alleen tekst-modus).
.setWidth(pixels)
Afbeelding breedte.
.setHeight(pixels)
Afbeelding hoogte.

Foutafhandeling

Gebruik try/catch rondom generate().

try{const r=await ai.generate("test")}catch(e){console.error(e.message)}

Voorbeelden

Tekst

const ai=new AIClient();ai.setApiKey("sk_...").setType("text").setModel("openai").setSystemPrompt("Je bent hulpvaardig.");const t=await ai.generate("Wat is AI?");console.log(t);

Afbeelding

const ai=new AIClient();ai.setApiKey("sk_...").setType("image").setModel("flux").setWidth(1920).setHeight(1080);const url=await ai.generate("Futuristische stad");const img=document.createElement('img');img.src=url;document.body.appendChild(img);
