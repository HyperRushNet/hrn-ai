AIClient Reference

Een compacte wrapper voor Pollinations AI.

Installatie

Kopieer de class naar je script.

class AIClient{constructor(){this.c={k:'',m:'openai',s:'You are helpful',h:[],t:0.7,sd:-1,j:!1}}setKey(v){return v&&(this.c.k=v),this}setModel(v){return v&&(this.c.m=v),this}setSys(v){return v&&(this.c.s=v),this}setTemp(v){return this.c.t=parseFloat(v),this}setSeed(v){return this.c.sd=parseInt(v),this}setJson(v){return this.c.j=v==='true',this}async gen(p){this.c.h.push({role:'user',content:p});const b={model:this.c.m,messages:[{role:'system',content:this.c.s},...this.c.h],temperature:this.c.t,seed:this.c.sd};if(this.c.j)b.response_format={type:'json_object'};const h={'Content-Type':'application/json'};if(this.c.k)h.Authorization=`Bearer ${this.c.k}`;try{const r=await fetch('https://gen.pollinations.ai/v1/chat/completions',{method:'POST',headers:h,body:JSON.stringify(b)}),d=await r.json();if(!r.ok)throw new Error(d.error?.message||'Error');const t=d.choices[0].message.content;return this.c.h.push({role:'assistant',content:t}),t}catch(e){throw this.c.h.pop(),e}}}

Configuratie Methods

Alle configuratie-methodes retourneren this voor chaining.

.setApiKey(key)
Stelt de API sleutel in.
ParameterTypeBeschrijving
keystringDe API key (bv. pk_...).
.setModel(modelId)
Stelt het model in.
ParameterTypeBeschrijving
modelIdstringModel ID (bv. "openai", "gemini-search").
.setSystemPrompt(prompt)
Stelt de systeem instructie in (persona).
ParameterTypeBeschrijving
promptstringInstructies voor de AI.
.setTemperature(value)
Stelt de creativiteit/temperatuur in.
ParameterTypeBeschrijving
valuenumberWaarde tussen 0.0 en 2.0. Standaard: 0.7.
.setSeed(value)
Stelt de seed in voor reproduceerbaarheid.
ParameterTypeBeschrijving
valuenumberInteger. Standaard: -1 (random).
.setJsonMode(boolean)
Forceert JSON output.
ParameterTypeBeschrijving
booleanbooleantrue om JSON modus aan te zetten.

Actie Methods

.generate(prompt) ASYNC
Genereert een antwoord op basis van de prompt en de geschiedenis.
ParameterTypeBeschrijving
promptstringDe input van de gebruiker.

Returns: Promise<string> – Het antwoord van de AI.

Voorbeeld Gebruik

const ai = new AIClient();

// Configuratie
ai.setApiKey("pk_...")
  .setModel("gemini-search")
  .setSystemPrompt("Je bent een bot.");

// Generatie
const text = await ai.generate("Hallo!");
