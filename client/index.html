AIClient v1.0.3

Minimalist wrapper for Pollinations AI.

Installation

HTML
<script src="https://cdn.jsdelivr.net/gh/HyperRushNet/hrn-ai/client/1.0.3.min.js"></script>

Text Generation

JavaScript
const ai = new AIClient().setApiKey("YOUR_KEY").setModel("openai");

try {
  const text = await ai.generate("Hello world");
  console.log(text); 
} catch (err) {
  console.error(err.message);
}

Image Generation

JavaScript
const ai = new AIClient().setApiKey("YOUR_KEY").setType("image");

try {
  const blob = await ai.generate("A futuristic car");
  const url = URL.createObjectURL(blob);
  console.log(url);
} catch (err) {
  console.error(err.message);
}

Methods

MethodDescription
setApiKey(str)Required for all requests.
setModel(str)Set AI model ID.
setType(str)Use 'text' or 'image'.
setDimensions(w, h)Set image resolution.
clearHistory()Reset conversation history.
generate(prompt)Execute async request.
