Quickstart

Initialize the engine and execute your first generation in under 30 seconds.

cdn setup
<script src="https://cdn.jsdelivr.net/gh/HyperRushNet/hrn-ai/client/1.0.3.min.js"></script>
<script>
  const ai = new AIClient().setApiKey("sk-pollinations-...");
</script>

Text Intelligence

The SDK handles JSON parsing, choice selection, and system prompt injection automatically.

javascript
const response = await ai
  .setModel("openai")
  .setSystemPrompt("You are a senior dev.")
  .generate("Explain hydration in React.");

console.log(response); // Returns clean string

Image Synthesis

Images are returned as raw Blobs to prevent memory leaks in the browser.

javascript
const blob = await ai
  .setType("image")
  .setDimensions(1280, 720)
  .generate("A neon city in the year 2099.");

const url = URL.createObjectURL(blob);
