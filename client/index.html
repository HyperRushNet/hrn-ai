.generate(prompt)

Triggers the API request using the current config state.

/**
 * @param {string} prompt - Instruction for the AI (required)
 * @returns {Promise} Text response or Image Blob
 * @throws {Error} If API Key is missing or prompt is empty
 */
const result = await ai.generate("What is the speed of light?");

• Text Mode: Appends role user and assistant to history. Auto-trims history to historyLimit.

• Image Mode: Uses response_format: "b64_json" and converts base64 to a raw image/png Blob.

Internal State Logic

History Management

In text mode, the engine keeps a sliding window of conversations. When history.length exceeds 2 * historyLimit, the oldest pair is spliced out to save tokens.

Deterministic Seeds

If no seed is set via setSeed(), the engine generates a random integer: Math.floor(1e9 * Math.random()) for every request.

Error Codes

Retry Trigger (429/5xx)

If enabled, the SDK waits retryDelay before re-executing generate().

AbortError

Triggered by the internal AbortController if the timeout limit is reached.
