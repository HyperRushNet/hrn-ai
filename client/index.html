.generate(prompt)

The only asynchronous method that triggers network activity.

PROMISE DYNAMIC RETURN

This method compiles all previous configurations (model, type, history) and sends a request to the Pollinations API. It is designed to be the final call in your chain. 

/**
 * @param {string} prompt - Non-empty string instruction
 * @returns {Promise} Text if .setType('text'), Blob if .setType('image')
 */
const output = await ai.generate("Your instruction");
Configuration

Chainable Setters

These methods return this (the instance), allowing for a fluent API design. They do not perform network requests.

.setModel(slug)

Sets the target model. Expects a string identifier from the registry below.

.setType(mode)

Accepts 'text' or 'image'. Determines the endpoint and .generate() return type.

.setRequestTimeout(ms)

Expects number. Aborts the request if the server doesn't respond within the window.

.setDimensions(w, h)

Only applicable for 'image' type. Sets resolution parameters.

.setRetry(bool, count, delay)

Configures internal retry logic for 429 and 5xx response codes.
