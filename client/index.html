.generate(prompt)

Asynchronous method derived from the source: triggers net activity & history management.

// Example Implementation
const ai = new AIClient().setApiKey('sk-...');
const output = await ai.generate("Explain quantum entanglement.");

Internally uses an AbortController linked to your timeout config. If type is 'image', it returns a Blob; if 'text', it returns a string and updates the session history.

Logic

History & Seed Handling

Auto-Splicing

When history.length > 2 * historyLimit, the SDK removes the oldest user/assistant pair automatically.

Randomized Seeds

Requests default to Math.floor(1e9 * Math.random()) if no manual seed is provided via setSeed().

Error Handling

Status 429 / 5xx

Triggers recursive generate() if retries are enabled.

AbortError

Thrust when timeout is exceeded. Configured via setTimeout().
